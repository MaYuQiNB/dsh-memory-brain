# 记忆脑 · Memory Brain

一个给 DSH（DeepSeek Harness）用的**仿人脑记忆系统**插件。

- **自动贴标签**：每个任务（Session）里的每一轮对话结束后，自动编码成一条带标签的「情节记忆」（episode）。
- **按时间遗忘（到点删内容）**：记忆强度按艾宾浩斯遗忘曲线随时间衰减；低于阈值先「消退」，再「遗忘」。**一旦到达遗忘时间，记忆的可读内容会被永久删除**——用户消息、助手回复、摘录、标签、任务标题全部清除且不可恢复，只剩一个空的「已遗忘」墓碑（稍后被自动清理）。反复被想起（recall / 唤醒）会强化；固定（pin）的记忆永不遗忘。
- **是否遗忘可以设置**：设置面板有「启用遗忘」总开关——关掉后所有记忆冻结（不衰减、不到点删除、内容保留），重新开启后从冻结时刻继续计算；每条记忆详情里也有「永不遗忘 / 恢复遗忘」的单项开关。默认开启遗忘。
- **结构化事实（批次1）**：每轮对话会抽取「主体-属性-值-时间」事实，存成独立条目（不是只存整段）；相同事实去重合并（次数 +1，不新建），同一主体同一属性出新值时旧值标记失效、检索只回最新。
- **摘要层 + 分层检索（批次2）**：每会话一句摘要、每日一条汇总、每周再汇总；检索按问题复杂度选层——简单问题查原始记忆/事实，复杂问题（总结/回顾/规划等）自动查周汇总或会话摘要。
- **可选：语义召回 / 时序关系（批次3，默认关）**：语义召回用**本地哈希向量**（2/3-gram，离线、不联网、不引入模型），关键词与向量双路合并；时序开关打开后检索会带回同一槽位的失效旧值（「以前是 X，现在是 Y」）。
- **8 个独立开关，逐项可回滚**：设置面板按三批分组，每个步骤单独开关；关掉即回滚该步（已有数据保留、可手动清空），不影响其它步骤和原有遗忘/pin 逻辑。
- **老数据可批量重跑 + 幂等**：「重建事实 / 重建摘要」是对**全部已有记忆**做全量重跑（不是只对新记忆生效）；事实 id 由 subject+attribute+value 确定性生成、重跑先清空再重建，所以同一库跑多少次都不会长出重复条目（增量模式也只合并不重复）。
- **召回有硬上限**：`recall` 每次最多返回 30 条（默认 8），分层合并后再截断；`facts` / `summaries` 各自有条数上限，工具文本逐条裁剪——不会把模型上下文塞爆。
- **固定问题基线**：`test/baseline.test.mjs` 用固定时钟 + 固定对话 + 固定问题集钉死分层/召回/事实结果，改完代码跑一遍即可对照回归。
- **巩固睡眠**：把标签相近的情节记忆合并成「语义记忆」（semantic），并清理彻底衰减的记忆——模仿睡眠中的记忆巩固。
- **可视化记忆网**：Web UI 里一整页记忆网络：节点是记忆，颜色是任务，连线是共享标签 / 同一任务 / 语义归属；支持缩放、拖拽、悬停、选中、任务与标签筛选、搜索、**时间旅行**（模拟未来 N 天后的遗忘）。
- **3D 立体视图**（默认）：记忆网络组织成一个可旋转缩放的 3D 模型——节点是球体（语义记忆是菱形多面体），彼此连线，**每个节点都标着名字**（任务名 · 第 N 轮），远近有透视与深度雾；**视角可以随便移动，操作也能自己改**：左键拖拽旋转、右键/中键/Shift+拖拽平移、滚轮缩放、方向键/WASD 移动、Q/E 转向、`+`/`-` 缩放、双击或 `R` 归位；设置面板可改旋转键/平移手势/三种灵敏度/上下反转/键盘布局/双击归位、**显示节点文字**，也可一键恢复默认；还能一键切回 2D 平面图。
- **节点文字可显隐 + 悬停看文字**：3D 画布默认显示每个节点的名称胶囊，可在设置里关掉；**即使关掉标签，把鼠标悬停在节点上也会弹出该节点的完整名称（任务名 · 第 N 轮）和一段文字摘要**，点击节点还会在详情卡里显示完整标题与内容。2D 视图不受影响。
- **全屏模式**：3D 模型一键占满整个屏幕（浏览器 Fullscreen API，不支持时退化为面板内沉浸模式）；全屏下只留悬浮控制条和「Esc 退出全屏」提示，点击节点弹出悬浮详情卡，界面让位给记忆网。
- **任务内嵌视图**：每个任务（会话）的 View 标签行里多一个「**记忆**」页签——打开任意任务就能看到**这个任务自己的** 3D 记忆网、记忆列表和详情操作，还能一键跳到全局面板并自动按该任务筛选。
- **QQ 聊天接入**：QQ 桥接（私聊/群）的对话也会自动进入记忆库——历史 QQ 会话回填 + 新消息实时捕获，带「QQ」来源标记，在记忆网里作为独立的「QQ 聊天」任务簇出现；QQ 会话里的 agent 同样能调用 `brain_memory` 回忆。
- **给 Agent 的记忆工具**：`brain_memory`（state / recall / remember / tag / untag / rehearse / forget / restore / pin / sleep / capture / settings / **facts / summaries / features / rebuild**），并在系统提示词里说明记忆库存在。

## 安装

需要 **DSH（DeepSeek Harness）桌面版 / 带 Web UI 的 profile**（在 DSH `0.2.2-rc.3` 上开发验证）。

1. 把本仓库放到本机：`git clone https://github.com/MaYuQiNB/dsh-memory-brain.git`，或直接下载 zip 解压。
2. 在 DSH 里用插件管理器安装这个**包目录**：调用 `plugin_manager` 的 `install_bundle`，`target` 填本目录的绝对路径。安装器会自动把它加入当前 profile 的 bundle 列表。
3. 打开/刷新 DSH Web UI：侧栏出现「记忆脑」图标；每个任务里多出「记忆」页签；`brain_memory` 工具与系统提示词段自动生效。

也可以手动在 `~/.dsh/profiles/<profile>/package.json` 的 `dsh.profile.bundles` 里加入本包（本地目录用 `link:` 依赖），或用 `plugin_manager` 的 `set_bundle` 开关。

记忆数据只存在本机 `$DSH_HOME/memory-brain.json`（默认 `~/.dsh/memory-brain.json`），不上传、不联网。

## 使用

1. 侧栏点「记忆脑」图标，打开记忆网（默认 **3D 立体视图**）。
2. 3D 操作：**左键拖拽旋转**、**右键/中键/Shift+左键拖拽平移**、**方向键/WASD 移动**、**Q/E 转向**、**滚轮或 `+`/`-` 缩放**、拖节点移动、点击节点打开右侧详情、hover 看提示、**双击画布或 `R` 归位**；画布右上可「复位视角」「自转」，也可切到「2D 平面」看老的平面网络。
3. 想看沉浸式大画面：点画布右上「**全屏**」，3D 模型会占满整个屏幕（`Esc` 或右上「退出全屏」返回）。全屏下点击节点会弹出悬浮详情卡，其余界面隐藏。
4. **在任务里看记忆**：打开任意任务 → 会话顶部 View 标签行点「**记忆**」→ 这个任务自己的 3D 记忆网 + 本任务记忆列表 + 详情操作；点「在记忆脑中打开」会跳到全局面板并自动按该任务筛选。
5. 首次安装会自动扫描最近的历史任务回填记忆（也可点「扫描历史」手动触发）。
6. 之后的每轮对话自动记入；时间越久节点越淡，最后变成灰色幽灵节点（可开关显示）。
7. 在右栏详情里给记忆加标签、唤醒、「**永不遗忘 / 恢复遗忘**」（单条记忆是否遗忘）、遗忘或恢复；「巩固睡眠」合并语义记忆；**遗忘时间可以在设置面板手动改**（「遗忘时间（天）」输入框 1–60 天，另有 7/14/30 天快捷按钮），设置面板里还有「**启用遗忘**」总开关（关掉后所有记忆冻结、不衰减也不删内容）。默认 **7 天**：普通记忆约第 7 天进入遗忘、**到点后内容被永久删除（不可恢复，只剩「已遗忘」墓碑）**，约第 13 天墓碑被清理；被想起过的更久。手动点「遗忘」可恢复（内容保留），只有到点自动遗忘才删内容。也可以直接对我说「把遗忘时间改成 X 天」「关掉遗忘」「开启遗忘」。
8. **分层记忆（v0.5）**：设置面板「记忆系统升级（可单独回滚）」里按三批分组有 8 个开关（事实抽取 / 去重 / 冲突替换 / 会话摘要 / 日周汇总 / 分层检索 / 语义召回 / 时序关系），下面显示事实与摘要计数，并提供「重建事实 / 清空事实 / 重建摘要 / 清空摘要」按钮；右栏还会显示「知识层」（主体 · 属性 → 值 ×次数）和「摘要层」（会话/每日/每周）两个可滚动列表。
9. **3D 操作自定义（v0.5.3）**：设置面板「3D 视角操作（可自定义）」里可以改旋转键（左/右键）、平移手势（右键/中键/Shift+左键/Alt+左键）、旋转/平移/缩放灵敏度（0.2–3）、上下反转、键盘布局（WASD/方向键/两者/关闭）、双击是否归位、**是否显示节点文字**，并提供「恢复默认操作」。也可以直接对 Agent 说「把 3D 旋转改成右键」「平移换成中键」「把节点文字关掉」。
9. 在对话里让 Agent 回忆：它可以直接调用 `brain_memory` 工具（检索本身会强化记忆），也可以查 `facts` / `summaries`，或让 `recall` 按复杂度自动选层。
10. **重跑与幂等**：「重建事实 / 重建摘要」= 对全部历史记忆全量重跑，可反复点，不会产生重复条目；想从零再来可先「清空」再重建。Agent 侧对应 `brain_memory action=rebuild target=all`。
9. **QQ 聊天**：侧栏「记忆脑」左栏会出现带 `QQ` 徽标的「QQ 聊天」任务（3D 网里自成一群）；QQ 桥接的新对话会在每轮结束后自动进入记忆库，可用 `brain_memory` 的 `recall tag="QQ"` 检索。

## 数据

- 记忆库存在 `$DSH_HOME/memory-brain.json`（原子写入），不属于任何会话，重启后还在。
- 会话日志是唯一真相：插件只在 `turn/end` 时从已提交的 Session 事件里读取这一轮。
- QQ 会话的识别依据是会话 cwd 含 `qq-bridge`（QQ 桥接把每个 QQ 私聊/群映射成一台 DSH 会话）；记忆带 `source: 'qq'` 与标签 `qq`，界面徽标显示「QQ」。
- 结构：

| 文件 | 作用 |
| --- | --- |
| `index.js` | 宿主半：`/memory-brain/*` HTTP 接口（含 `features` / `facts/*` / `summaries/*`）、`brain_memory` 工具、系统提示词段、实时捕获（含 QQ 识别与事实抽取）、历史回填（QQ 优先）、定时巩固/摘要重建 |
| `lib/memory-store.js` | 记忆库（编码 / 唤起 / 遗忘 / **到点删内容** / 恢复 / 巩固 / 检索 / 分层事实与摘要 / 持久化回调；记忆带 source 与墓碑标记） |
| `lib/memory-engine.js` | 纯函数记忆模型：遗忘曲线、标签提取、巩固聚类、图与统计 |
| `lib/fact-engine.js` | 纯函数结构化事实：规则抽取（中英）、去重合并、冲突替换、查询、离线哈希向量（批次1+批次3） |
| `lib/summary-engine.js` | 纯函数摘要层：会话/每日/每周摘要、问题复杂度分类、分层选择（批次2） |
| `client.js` | 客户端半：侧栏图标 + 整页记忆网（React + Canvas，3D 立体 / 2D 平面可切换；3D 用画家算法 + 透视轨道相机，每个节点都带名称标签；QQ 会话带徽标；设置面板含 8 个升级开关、知识层/摘要层列表） |
| `cordis.patch.yml` | 把 bundle 插进 Loader 的补丁 |
| `locale/{zh,en}.json` | 插件页显示名与说明 |
| `icon.svg` | 插件图标 |

## 已知边界

- 记忆只在 `turn/end` 后生成，进行中的一轮不会提前出现。
- 默认不记录子会话（`origin: 'subagent'`，例如队友 / 子代理）的对话，避免噪音淹没任务记忆。
- 自动回填只取最近 40 个普通任务 × 每任务最近 10 轮；QQ 会话另扫最多 8 个 × 每会话最近 20 轮。记忆总量上限由 `maxMemories` 控制（默认 600）。
- **遗忘时间默认 7 天**（可在设置里改 1–60 天）：普通记忆约第 3–4 天开始消退、**第 7 天左右到达遗忘时间时内容被永久删除（不可恢复，只剩空的「已遗忘」墓碑）**、约第 13 天墓碑被彻底清理；每次被想起都会延长，固定（pin）的记忆永不遗忘；更重要的长对话会略晚一点。
- **删内容发生在「到达遗忘时间」那一刻之后 10 分钟内**（每 10 分钟扫一次；插件重新加载时也会立即扫一次）。到点后 `restore` 会被拒绝（`content-purged`），数据文件里也查不到原文。
- **遗忘开关**：关掉「启用遗忘」后，整个遗忘时钟冻结（保持率、状态、图都不再变化，不衰减也不删内容）；重新开启时会把暂停时长整体平移，不会因为暂停期间「欠下的时间」一次性把所有记忆忘光。开关状态持久化在 `$DSH_HOME/memory-brain.json` 的 `settings.forgettingEnabled` / `forgettingPausedAt`。
- QQ 聊天记忆来自桥接会话，标题统一显示为「QQ 聊天」；QQ 消息里的桥接唤醒脚手架（当前时间/角色提示词等）会保留在记忆摘录里。
- QQ 桥接进程不需要重启：它只是通过 DSH API 创建/唤醒会话，新工具与新提示词在下一次请求生效；QQ 侧 agent 是否主动调用 `brain_memory` 由它自己决定（工具与提示词已提供）。
- 记忆的「保持率」是模型值（按艾宾浩斯曲线计算），不是真实认知测量。
- **事实抽取是纯规则启发式**（中英文模式，不调用模型、不联网），因此只抽取高置信度的第一人称/显式主体事实，会有漏抽与少量噪声；事实本身不参与遗忘曲线，但**来源记忆的内容被删光后对应事实也会失效**（`invalidReason='source-forgotten'`），摘要层在有内容被删时会整体清掉重建，避免“删了记忆却从摘要里读回来”。
- **批次3 的语义召回不是神经网络 embedding**：为满足「离线优先、不新增联网调用」，用的是本地字符 n-gram 哈希向量（96 维、L2 归一），只能做粗粒度相似度融合；若以后允许本地模型，可替换该模块实现而不改接口。
- **每个升级开关独立回滚**：关掉某一步只停用该步（已有数据保留，可手动清空）；`features` 与事实/摘要一起持久化在 `$DSH_HOME/memory-brain.json`，回滚不丢原始记忆。
- **召回上限**：一次 `recall` 最多 30 条（默认 8），`facts` 最多 50 条、`summaries` 每层最多 20 条；超出的先按相关度截断。**重建是全量重新抽**：对同一库重复执行结果一致（幂等），但会刷新 `lastSeenAt`/时间戳；想保留历史计数器可用增量模式（`clear=false`）。
- **3D 相机**：平移目标有世界边界（±20000），俯仰约 ±87°，可以从几乎正上/正下方看；触屏目前只有单指旋转，双指捏合缩放/平移尚未实现（桌面键鼠完整可用）。
- **3D 操作自定义**：旋转键、平移手势、旋转/平移/缩放灵敏度、上下反转、键盘布局、双击归位、节点文字开关都可保存；配置存在 `memory-brain.json` 的 `cameraControls` 里，重启/换页面不丢。旋转键与平移手势冲突时平移优先（例如把旋转设为右键、平移也设为右键，则右键拖拽是平移）。
- **节点文字**：关掉后 3D 画布不再绘制节点名称胶囊；悬停提示、点击详情、2D 平面视图都不受影响（2D 文字始终显示）。
