# 记忆脑 · Memory Brain

一个给 DSH（DeepSeek Harness）用的**仿人脑记忆系统**插件。

- **自动贴标签**：每个任务（Session）里的每一轮对话结束后，自动编码成一条带标签的「情节记忆」（episode）。
- **按时间遗忘（到点删内容）**：记忆强度按艾宾浩斯遗忘曲线随时间衰减；低于阈值先「消退」，再「遗忘」。**一旦到达遗忘时间，记忆的可读内容会被永久删除**——用户消息、助手回复、摘录、标签、任务标题全部清除且不可恢复，只剩一个空的「已遗忘」墓碑（稍后被自动清理）。反复被想起（recall / 唤醒）会强化；固定（pin）的记忆永不遗忘。
- **巩固睡眠**：把标签相近的情节记忆合并成「语义记忆」（semantic），并清理彻底衰减的记忆——模仿睡眠中的记忆巩固。
- **可视化记忆网**：Web UI 里一整页记忆网络：节点是记忆，颜色是任务，连线是共享标签 / 同一任务 / 语义归属；支持缩放、拖拽、悬停、选中、任务与标签筛选、搜索、**时间旅行**（模拟未来 N 天后的遗忘）。
- **3D 立体视图**（默认）：记忆网络组织成一个可旋转缩放的 3D 模型——节点是球体（语义记忆是菱形多面体），彼此连线，**每个节点都标着名字**（任务名 · 第 N 轮），远近有透视与深度雾；拖拽旋转、滚轮缩放、拖节点、点击看详情，也可一键切回 2D 平面图。
- **全屏模式**：3D 模型一键占满整个屏幕（浏览器 Fullscreen API，不支持时退化为面板内沉浸模式）；全屏下只留悬浮控制条和「Esc 退出全屏」提示，点击节点弹出悬浮详情卡，界面让位给记忆网。
- **任务内嵌视图**：每个任务（会话）的 View 标签行里多一个「**记忆**」页签——打开任意任务就能看到**这个任务自己的** 3D 记忆网、记忆列表和详情操作，还能一键跳到全局面板并自动按该任务筛选。
- **QQ 聊天接入**：QQ 桥接（私聊/群）的对话也会自动进入记忆库——历史 QQ 会话回填 + 新消息实时捕获，带「QQ」来源标记，在记忆网里作为独立的「QQ 聊天」任务簇出现；QQ 会话里的 agent 同样能调用 `brain_memory` 回忆。
- **给 Agent 的记忆工具**：`brain_memory`（state / recall / remember / tag / untag / rehearse / forget / restore / pin / sleep / capture），并在系统提示词里说明记忆库存在。

## 安装

需要 **DSH（DeepSeek Harness）桌面版 / 带 Web UI 的 profile**（在 DSH `0.2.1-rc.2` 上开发验证）。

1. 把本仓库放到本机：`git clone https://github.com/MaYuQiNB/dsh-memory-brain.git`，或直接下载 zip 解压。
2. 在 DSH 里用插件管理器安装这个**包目录**：调用 `plugin_manager` 的 `install_bundle`，`target` 填本目录的绝对路径。安装器会自动把它加入当前 profile 的 bundle 列表。
3. 打开/刷新 DSH Web UI：侧栏出现「记忆脑」图标；每个任务里多出「记忆」页签；`brain_memory` 工具与系统提示词段自动生效。

也可以手动在 `~/.dsh/profiles/<profile>/package.json` 的 `dsh.profile.bundles` 里加入本包（本地目录用 `link:` 依赖），或用 `plugin_manager` 的 `set_bundle` 开关。

记忆数据只存在本机 `$DSH_HOME/memory-brain.json`（默认 `~/.dsh/memory-brain.json`），不上传、不联网。

## 使用

1. 侧栏点「记忆脑」图标，打开记忆网（默认 **3D 立体视图**）。
2. 3D 操作：**拖拽空白旋转**、**滚轮缩放**、拖节点移动、点击节点打开右侧详情、hover 看提示；画布右上可「复位视角」「自转」，也可切到「2D 平面」看老的平面网络。
3. 想看沉浸式大画面：点画布右上「**全屏**」，3D 模型会占满整个屏幕（`Esc` 或右上「退出全屏」返回）。全屏下点击节点会弹出悬浮详情卡，其余界面隐藏。
4. **在任务里看记忆**：打开任意任务 → 会话顶部 View 标签行点「**记忆**」→ 这个任务自己的 3D 记忆网 + 本任务记忆列表 + 详情操作；点「在记忆脑中打开」会跳到全局面板并自动按该任务筛选。
5. 首次安装会自动扫描最近的历史任务回填记忆（也可点「扫描历史」手动触发）。
6. 之后的每轮对话自动记入；时间越久节点越淡，最后变成灰色幽灵节点（可开关显示）。
7. 在右栏详情里给记忆加标签、唤醒、置顶、遗忘或恢复；「巩固睡眠」合并语义记忆；**遗忘时间可以在设置面板手动改**（「遗忘时间（天）」输入框 1–60 天，另有 7/14/30 天快捷按钮）——默认 **7 天**：普通记忆约第 7 天进入遗忘、**到点后内容被永久删除（不可恢复，只剩「已遗忘」墓碑）**，约第 13 天墓碑被清理；被想起过的更久。手动点「遗忘」可恢复（内容保留），只有到点自动遗忘才删内容。也可以直接对我说「把遗忘时间改成 X 天」。
8. 在对话里让 Agent 回忆：它可以直接调用 `brain_memory` 工具（检索本身会强化记忆）。
9. **QQ 聊天**：侧栏「记忆脑」左栏会出现带 `QQ` 徽标的「QQ 聊天」任务（3D 网里自成一群）；QQ 桥接的新对话会在每轮结束后自动进入记忆库，可用 `brain_memory` 的 `recall tag="QQ"` 检索。

## 数据

- 记忆库存在 `$DSH_HOME/memory-brain.json`（原子写入），不属于任何会话，重启后还在。
- 会话日志是唯一真相：插件只在 `turn/end` 时从已提交的 Session 事件里读取这一轮。
- QQ 会话的识别依据是会话 cwd 含 `qq-bridge`（QQ 桥接把每个 QQ 私聊/群映射成一台 DSH 会话）；记忆带 `source: 'qq'` 与标签 `qq`，界面徽标显示「QQ」。
- 结构：

| 文件 | 作用 |
| --- | --- |
| `index.js` | 宿主半：`/memory-brain/*` HTTP 接口、`brain_memory` 工具、系统提示词段、实时捕获（含 QQ 识别）、历史回填（QQ 优先）、定时巩固 |
| `lib/memory-store.js` | 记忆库（编码 / 唤起 / 遗忘 / **到点删内容** / 恢复 / 巩固 / 检索 / 持久化回调；记忆带 source 与墓碑标记） |
| `lib/memory-engine.js` | 纯函数记忆模型：遗忘曲线、标签提取、巩固聚类、图与统计 |
| `client.js` | 客户端半：侧栏图标 + 整页记忆网（React + Canvas，3D 立体 / 2D 平面可切换；3D 用画家算法 + 透视轨道相机，每个节点都带名称标签；QQ 会话带徽标） |
| `cordis.patch.yml` | 把 bundle 插进 Loader 的补丁 |
| `locale/{zh,en}.json` | 插件页显示名与说明 |
| `icon.svg` | 插件图标 |

## 测试

```powershell
node --test --test-isolation=none test/engine.test.mjs test/store.test.mjs test/host.test.mjs
```

> 在这套 DSH 沙箱里，Node test runner 默认会为每个测试文件起子进程，而子进程管道会被沙箱拒绝（`spawn EPERM`）。`--test-isolation=none` 让所有测试在同一个进程里跑，沙箱内外都可用；普通环境也可以直接用 `node --test test/`。

- `test/engine.test.mjs`：遗忘曲线 / 标签 / 巩固 / 图 的纯函数测试。
- `test/store.test.mjs`：记忆库端到端（编码、衰减、遗忘、恢复、固定、巩固、容量、持久化往返、快照形状、QQ 来源）。
- `test/host.test.mjs`：宿主集成（路由、工具、提示词段、历史回填、实时捕获、QQ 会话识别与回填、QQ 标题回退）。

## 已知边界

- 记忆只在 `turn/end` 后生成，进行中的一轮不会提前出现。
- 默认不记录子会话（`origin: 'subagent'`，例如队友 / 子代理）的对话，避免噪音淹没任务记忆。
- 自动回填只取最近 40 个普通任务 × 每任务最近 10 轮；QQ 会话另扫最多 8 个 × 每会话最近 20 轮。记忆总量上限由 `maxMemories` 控制（默认 600）。
- **遗忘时间默认 7 天**（可在设置里改 1–60 天）：普通记忆约第 3–4 天开始消退、**第 7 天左右到达遗忘时间时内容被永久删除（不可恢复，只剩空的「已遗忘」墓碑）**、约第 13 天墓碑被彻底清理；每次被想起都会延长，固定（pin）的记忆永不遗忘；更重要的长对话会略晚一点。
- **删内容发生在「到达遗忘时间」那一刻之后 10 分钟内**（每 10 分钟扫一次；插件重新加载时也会立即扫一次）。到点后 `restore` 会被拒绝（`content-purged`），数据文件里也查不到原文。
- QQ 聊天记忆来自桥接会话，标题统一显示为「QQ 聊天」；QQ 消息里的桥接唤醒脚手架（当前时间/角色提示词等）会保留在记忆摘录里。
- QQ 桥接进程不需要重启：它只是通过 DSH API 创建/唤醒会话，新工具与新提示词在下一次请求生效；QQ 侧 agent 是否主动调用 `brain_memory` 由它自己决定（工具与提示词已提供）。
- 记忆的「保持率」是模型值（按艾宾浩斯曲线计算），不是真实认知测量。
